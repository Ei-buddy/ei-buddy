# Empresas

A API de Empresas permite criar, consultar, listar, alterar e excluir empresas, habilitando-as para emissão de todos os documentos fiscais oferecidos pela Focus NFe.

Importante: esta API opera exclusivamente no ambiente de produção. Para testes, utilize o parâmetro opcional `dry_run=1` quando disponível, para simular a operação sem efetivar a persistência.
