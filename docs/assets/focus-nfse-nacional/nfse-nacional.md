# NFSe Nacional

Por meio desta API é possível realizar operações com o webservice da NFS-e Nacional (Nota Fiscal de Serviço Nacional). Para emissão de NFS-e no padrão específico de um município, consulte a [API específica](https://doc.focusnfe.com.br/reference/nfse) deste documento fiscal.
